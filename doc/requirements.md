# PicPaste 产品需求基线（macOS 27）

## 1. 产品目标与使用场景

离线、启动快、待机轻量的菜单栏应用。用户通过全局快捷键截取当前屏幕，交互式选择区域，直接复制或保存 PNG；后续可将图片贴在桌面上，标注、识别文字和制作手动滚动长图。优先保证每天可用的基本操作闭环，而非堆积未验收功能。

## 2. 平台与不可变范围

- **操作系统**：仅 macOS 27.0 及以上；不设计 macOS 14–26 兼容层。
- **架构**：arm64，Apple Silicon；不提供 x86_64 或 Universal 2。
- **语言**：Swift 6.4、Swift 6 语言模式。AppKit 承担非标准窗口与鼠标交互，SwiftUI 承担设置及标准界面。
- **离线**：捕获、标注、OCR、二维码、拼图均在本地完成，无强制登录、无服务端或遥测依赖。
- **输出**：仅 PNG 文件，原生剪贴板应可在 Preview、Notes 等系统应用中直接粘贴；透明圆角保留真正的 Alpha 值。
- **发行**：首版单一 App；不预设 Lite/Full / Add-on，也不强制系统扩展和额外 Helper。

## 3. 阶段和用户故事

### P0：截图闭环（必须先设备验收）

- R-001 菜单栏应用：启动、退出、打开设置、截图入口；不出现多余 Dock 窗口。支持至少一个稳定的全局截图快捷键。
- R-002 使用 ScreenCaptureKit 捕获鼠标所在显示器的完整冻结画面；展示权限拒绝、撤销和捕获失败的可恢复提示。
- R-003 AppKit 原生浮层中拖动选区、移动已有选区、八手柄缩放；Escape 取消、Enter 确认。显示器断连或截图过期时停止，不能悄悄裁剪错误显示器。
- R-004 同一张源图经统一像素裁剪，复制到 NSPasteboard 或保存 PNG；默认文件名包含时间戳，不能静默覆盖同名文件。
- R-005 可设置 0–64 **源图像物理像素**的透明圆角半径；剪贴板和 PNG 采用一致的渲染结果。默认 0。
- R-006 原始图像与截图选区的坐标、色彩和 Alpha 必须一致；分别验证 1×/2× 和负桌面坐标。
- R-007 必须产生 arm64 可安装开发 App；macOS 27 真机交互验收不由 CI 或截图模拟代替。

### P1：截图易用性和悬浮贴图

- R-101 可配置截图快捷键、快捷键冲突告警与回滚、快捷键设置持久化、启动时恢复。
- R-102 全图/窗口截图模式和点击窗口候选；9×9 像素放大镜和 HEX 取色。
- R-103 将剪贴板或截取图像创建为多个独立置顶贴图；缩放、透明度、显式移动、关闭、焦点控制。
- R-104 鼠标穿透必须有**稳定且可验证的恢复路径**（菜单栏操作及可配置快捷键）；不能让用户失去贴图控制。

### P2：标注与编辑

- R-201 线、箭头、画笔、矩形、椭圆、文字（中文/英文）、马赛克和模糊。
- R-202 非破坏性标注、Undo / Redo；每次复制/导出由源像素与标注模型确定性生成。
- R-203 文本用 macOS 字体系统与原生 IME；工具栏遵循系统外观、降低透明度等可访问性设置。

### P3：本地智能功能

- R-301 Apple Vision 识别中文/英文文字，支持行、词和可行时的字级选取与复制。
- R-302 用户手动触发二维码识别，复制识别结果；不自动访问或打开二维码中的链接。
- R-303 所有 OCR / QR 操作无网络依赖；失败不能影响截图、PNG 或贴图基本功能。

### P4：手动滚动长截图

- R-401 用户手动纵向或横向滚动；只抓取选定区域，后续帧与已确认片段自动拼接。
- R-402 明确提示匹配失败，不在没有可信重叠时虚构图像；允许暂停、裁尾、从可信片段继续。
- R-403 允许配置固定页眉页脚/侧栏排除区域；提供实时缩略预览和复核；PNG 采用有界内存或流式输出。
- R-404 30k/60k 大图边界、临时文件清理、取消、重拍与真实网页/文档场景独立验证。

### P5：质量、性能、发布

- R-501 测量真实启动时间、快捷键延迟、空闲 CPU/RSS、多贴图响应；保留原始环境、结果、失败样例。
- R-502 Developer ID 签名、公证、Gatekeeper 首次下载和回滚检查，以及正式发行审批。

## 4. 本次不做

- Windows、Linux、Intel Mac、macOS 26 及更早版本。
- Rust/WGPU/egui、Electron、WebView、必须运行的 OCR Helper、双版本差异化打包。
- 自动滚动长截图（旧项目最终将自动滚动排除；未来若重新纳入须新增 Issue 和 ADR）。
- JPEG/WebP 等输出格式、上传云端、登录、AI 生成/远程识别。
- 未经测量即宣传特定性能指标；未经真机操作即声称截图或贴图可用。

## 5. 需求变更方式

用户明确提出的范围变化先更新对应 Issue，涉及长期范围或架构时同步新增 ADR 并修改本文件；PR 描述关联 Issue，功能验收与进度以 Issue 为准。
