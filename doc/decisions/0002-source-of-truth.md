# ADR-0002：薄 AGENTS.md、doc 常驻规范、GitHub Issues 动态进度

- 状态：已选定（产品约束，2026-10-29）
- 背景：旧项目在 README、STATUS、TASKS、REMAINING 和 Issues 中重复维护进度，形成多个需要同步的事实源。
- 决策：`AGENTS.md` 仅为索引；长期有效且**随实际变更持续更新**的需求、架构、协作、验收与 ADR 存放 `doc/`；Issue 唯一维护进度、范围与当前验收状态；PR 保存代码差异、CI、真实设备证据。
- 不允许：AGENTS.md 粘贴长篇规则；在多个文档中重复写完成率、CI 最新编号；凭模拟测试自动关闭设备验收 Issue。
- 变更方式：影响稳定约束的 PR 必须同步修改对应文档，重大设计决策通过新增 ADR 记录；任务状态直接通过 Issue 勾选和评论变更。
- 代价：查看最新项目进度需要 GitHub Issues 可访问；文档不会提供离线任务状态快照。
